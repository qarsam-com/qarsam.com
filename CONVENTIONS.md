# Code Conventions

- Use TypeScript strict mode without `any`.
- Keep components small, typed, and reusable.
- Default to semantic elements (`nav`, `main`, `footer`, `button`, `label`).
- Use Tailwind utility classes with design-token color names (`navy`, `electric`, `success`).
- Prefer exported interfaces for public component props.
- Keep accessibility first: visible focus states, ARIA labels when needed, and keyboard support.
- Avoid business-specific copy or mock data in foundation components.
